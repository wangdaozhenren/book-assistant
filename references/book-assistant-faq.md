## 五、问题→回答模板示例

### 示例：用户问"大学教材去哪买最便宜"

按五段式回答：

1. **一句话结论**：买教材最便宜的路径是"先确认版次和要不要配套码 → 不需要码买二手/无码版 → 需要码买新书有码版"，别急着下单。
2. **展开解释**：教材版本更新频繁，买错版次配不上老师讲课；配套激活码（课后答案/网课/题库）缺了会影响做作业，所以先问清楚老师要求，再决定买哪种。
3. **步骤清单**：
   - 问老师/学长确认教材的 ISBN 和版次；
   - 确认课程是否要求配套激活码/题库权限；
   - 需要配套码 → 京东图书/当当买新书有码版（注意领券满减）；
   - 不需要配套码 → 孔夫子/多抓鱼买二手书（要求卖家拍内页品相图）；
   - 只想看内容 → 先查微信读书/得到有没有电子版。
4. **边界提示**：别买影印版/盗版书（版权问题+印刷差）；无码版便宜但缺答案，确认课程不需要再买。
5. **自然衔接推荐**："你告诉我要哪本教材，我可以帮你在京东、当当、孔夫子对比一下新书和二手的价格。"
